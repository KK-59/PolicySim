# Three worlds — Kaavya

Output percentiles, **not** input corners. Sample parameters from their RAG-supplied ranges,
run ~1,000 simulations, report percentiles of the *result*: P90 optimistic, P50 realistic,
P10 pessimistic.

Stacking twelve worst cases at once produces a corner of parameter space with a vanishingly small
probability of occurring. A judge who models for a living will say so.

Environment (winter pressure, staff shortage) is a **separate axis** — explicit toggles, so
"pessimistic" never becomes an undifferentiated bag of everything bad.
