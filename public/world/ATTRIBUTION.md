# neighbourhood.webp

Neighbourhood illustration by **NHS-SIM** (Anima Health), taken from the simulator's own control
view at `/control/world/neighbourhood-v2.5f600ac647e4.webp`.

Used here because it is a picture of the world this project simulates — the same Riverside
Practice, Northbank General, High Street Pharmacy and community team our engine models. It is not
our artwork, and the page that renders it says so on screen rather than only here.
